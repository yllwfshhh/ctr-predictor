Peeking into the secrets of Cardiovascular Health

A Faster RCNN Approach to CT Ratio Calculation and Cardiovascular Health Analysis.

About

  • Automated CTR Prediction Tool

    Developed a full-stack Django web application that automates Cardiothoracic Ratio (CTR) prediction, achieving 98.4% accuracy using a Faster R-CNN model.

  • Saving Time and Decreasing Human Error

    Traditionally, measuring heart size on X-rays is done by hand. This AI tool automates the process, reducing the time needed by 67%—from one minute down to just 20 seconds—while making the results more reliable for doctors.

  • Model Architecture

    I implemented a Faster R-CNN framework utilizing a ResNet backbone to achieve superior feature extraction. This architecture accurately segments the heart and lungs to calculate the CT ratio and identify calcification in real-time.

  • Aortic calcification

    This tool also looks for calcium buildup (calcification) and gives a simple Health Rank. This helps doctors quickly see which patients need the most urgent care.
